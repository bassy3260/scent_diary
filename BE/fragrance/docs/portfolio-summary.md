## 이력서 bullet

- PostgreSQL 스키마에 Flyway를 도입해 마이그레이션 이력을 관리 체계화하고, 소프트 삭제-UNIQUE 제약 충돌 등 P0~P2급 데이터 정합성 결함 다수를 실제 운영 데이터 손실 없이 수정
- DB 트리거 + Transactional Outbox 패턴으로 "향수 데이터 수정 → 임베딩/검색엔진 자동 동기화" 파이프라인을 구축해, 수동 재적재에 의존하던 데이터 정합성 문제를 편집 경로(SQL 직접 수정 포함)에 무관하게 해결
- 협업 필터링 추천의 IDF 가중치가 설계 의도(소수 취향 보존)를 실제로 달성하는지 8-seed ablation 실험으로 검증해 결함을 발견하고, 목표 지표를 65.3%→95.2%로 개선
- Elasticsearch 전체 재색인을 Reindex+Alias Swap 방식으로 개편해 재색인 중 검색 서비스 중단 없이 무중단 배포 가능하도록 개선

---

## 3~4문장 요약 (프로젝트 설명란용)

> 백엔드 안정성을 DB→데이터 정합성→추천 정확도 순으로 단계적으로 리팩토링했다. 실서비스 중인 DB에 Flyway를 안전하게 도입하고 스키마 결함을 수정했으며, "향수 데이터를 고쳐도 임베딩/검색/추천에 반영이 안 되는" 문제를 DB 트리거+Outbox 패턴으로 근본 해결해 편집 경로에 무관한 자동 동기화 파이프라인을 구축했다. 이 과정에서 협업 필터링 추천의 핵심 로직(IDF 가중치)이 설계 의도를 실제로 달성하지 못하는 결함을 정량 평가(leave-one-out, 8-seed ablation, 95% 신뢰구간)로 발견해 수정했고, 검색 엔진 무중단 재색인 구조까지 구현해 전체 파이프라인을 프로덕션 수준으로 끌어올렸다.

## 구성 요소별 요약

| 항목 | 문제상황 | 해결 | 성과 |
|---|---|---|---|
| **DB 안정성** | 스키마 변경 이력 관리 없음, 소프트 삭제+UNIQUE 제약 충돌 등 P0~P2 결함 다수 | Flyway 도입(baseline-on-migrate로 기존 운영 데이터 보존), 결함별 마이그레이션 작성 | 실데이터 무손실로 스키마 이력화, 재현 가능한 마이그레이션 체계 확보 |
| **데이터 정합성 파이프라인** | 향수 수정/삭제가 임베딩·ES·CF 추천에 반영 안 됨(수동 스크립트 의존) | DB 트리거→Outbox 테이블→워커→ML 단건 임베딩→ES 단건 upsert/delete, DLQ 재시도 | 편집 경로(SQL 직접 포함) 무관하게 자동 동기화, soft-delete/복구 양방향 end-to-end 검증 |
| **CF 추천 정확도 개선** | IDF 가중치가 "소수 취향 보존" 목적을 실제로 달성하는지 검증된 적 없음 | Hit Rate/NDCG 평가체계 설계 → 실데이터/합성데이터 ablation → 유저기준 IDF의 표본 편향 결함 발견 | 목표 지표(희귀 신호 생존율) 65.3%→95.2%, 신뢰구간 비겹침으로 통계적 확실성 확보 |
| **ES 무중단 재색인** | 전체 재색인 시 인덱스 직접 덮어써 검색 불안정, 매핑 변경 불가 | Reindex + Alias Swap (새 인덱스 적재 후 별칭 원자적 스왑, 옛 인덱스 정리) | 재색인 중 검색 API 끊김 없음, 매핑 변경 가능한 구조로 전환 |

## STAR (면접 답변용)

- **S**: 향수 정보를 수정해도 검색 결과와 추천 결과에 반영되지 않는 문제를 발견 — DB, 캐시(ES/임베딩), 추천 모델(CF) 세 파이프라인이 서로 단절되어 있었음.
- **T**: 근본 원인을 추적해 안전하게 고치고, 그 과정에서 드러난 추천 정확도 자체의 결함까지 정량적으로 검증해 개선한다.
- **A**: DB 트리거+Outbox 패턴으로 편집 경로 불문 자동 동기화 파이프라인 구축 → CF/검색 캐시가 서버 재시작 전까지 절대 안 바뀌는 문제를 dirty-check/주기적 재로드로 해결 → 이 과정에서 "IDF가 실제로 소수 취향을 보존하는가"라는 검증되지 않은 가정을 발견해 8-seed ablation으로 실측 → ES 재색인 구조를 무중단 방식으로 재설계.
- **R**: 데이터 정합성 문제 근본 해결(실측 검증 완료), CF 추천 목표 지표 65.3%→95.2%, 검색 인프라 무중단 재색인 확보 — 세 계층 모두 프로덕션 수준으로 개선.
